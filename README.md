\# 🧠 Project: เพื่อนกูเอง



โปรเจกต์นี้สร้างขึ้นเพื่อศึกษาสิ่งมีชีวิตชนิดหนึ่ง

ที่สามารถ \*\*ออนไลน์ทั้งวัน แต่ตอบแชทกูหลัง 7 ชั่วโมง\*\*



\## 📌 Features



\* ✅ กวนตีนเก่ง

\* ✅ พูดมากแต่สาระไม่มี

\* ✅ เวลาเรียกไม่มา

\* ✅ เวลามีเรื่องเสือกมาคนแรก

\* ✅ ยืมเงินจำแม่น

\* ❌ คืนเงินจำไม่ได้

\* ❌ ใช้สมองก่อนพูด

\* ❌ มีความรับผิดชอบ



\## 💻 System Requirements



```txt

CPU: สมองอย่างน้อย 1 Core

RAM: ไม่ทราบ เพราะเหมือนไม่เคยโหลดข้อมูล

Storage: เต็มไปด้วยเรื่องชาวบ้าน

Internet: แรงเฉพาะตอนเล่นเกม

```



\## 🚀 Installation



ไม่แนะนำให้ติดตั้ง

กูติดตั้งมาแล้ว เอาออกไม่ได้



```bash

git clone https://github.com/ไอ้สัส/เพื่อนเหี้ย.git

cd เพื่อนเหี้ย

npm uninstall friend

```



ผลลัพธ์:



```txt

ERROR: This idiot is permanently installed.

```



\## 🐛 Known Issues



\* ชอบบอกว่า `"กำลังไป"` ทั้งที่ยังไม่อาบน้ำ

\* บอก `"เกมสุดท้าย"` แล้วเล่นต่ออีก 8 เกม

\* เวลาแพ้ = โทษเน็ต

\* เวลาชนะ = บอกตัวเองแบก

\* บอก `"เดี๋ยวคืน"` แล้วเดี๋ยวนั้นไม่เคยมาถึง

\* ชอบถาม `"อยู่ไหน"` ทั้งที่แชร์โลเคชันให้แล้ว

\* ชอบพูด `"กูรู้"` แล้วอีก 5 นาทีถามใหม่
